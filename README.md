# RUL Evaluation Protocol Inflation Study

Reproducibility package for the manuscript:

**Revisiting Evaluation Protocols for Bearing Remaining Useful Life Prediction: The Effects of Labeling and Temporal Splitting Across Multiple Datasets**

## Contents

- `reproducibility/` contains preprocessing scripts, converged training and split-sensitivity runners, result JSON files, table/figure generators, and prevalence survey materials.
- `manuscript_revised_v6.pdf` is the latest manuscript.
- `figures/` contains the figures used in the manuscript.

## Data

The scripts expect processed data under `reproducibility/data/processed/` with `XJTU-SY/`, `PHM2012/`, and `IMS/` subdirectories. Raw datasets are publicly available from their original sources.

## Reproducibility

See `reproducibility/README.md` for environment, data layout, and command-line examples.
